# Skill: defining-features

## Overview
Guides the user to define the list of features for the project.

## Checklist
1. Use the Read tool on `.specs/memory/features.md`. If it has content, exit and do nothing.
2. Ask the user to list the features they want to build (e.g., Auth, Database).
3. Use the Write tool to save the features to `.specs/memory/features.md` in a structured list format.
