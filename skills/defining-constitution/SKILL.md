# Skill: defining-constitution

## Overview
Guides the user to define the core project rules, architecture, and constraints.

## Checklist
1. Use the Read tool on `.specs/memory/constitution.md`. If it has content, exit and do nothing.
2. Ask the user about their project vision, tech stack, and core rules.
3. Once gathered, use the Write tool to save the definitions to `.specs/memory/constitution.md` following standard markdown formatting.
