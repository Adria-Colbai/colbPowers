# Memory Specs Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modify the local plugin skills to enforce reading, writing, and initializing `.specs/memory/` documents.

**Architecture:** We will modify the markdown instructions inside `skills/*/SKILL.md` to inject strict verification, context-loading, and synchronization steps. We will also create two new skills for defining missing memory files.

**Tech Stack:** Markdown (Prompt Engineering)

---

### Task 1: Create Initialization Skills

**Files:**
- Create: `skills/defining-constitution/SKILL.md`
- Create: `skills/defining-features/SKILL.md`

- [ ] **Step 1: Create defining-constitution skill**

```bash
mkdir -p skills/defining-constitution
```

- [ ] **Step 2: Write defining-constitution SKILL.md**

```bash
cat << 'EOF' > skills/defining-constitution/SKILL.md
---
name: defining-constitution
description: Use when starting a new project or when .specs/memory/constitution.md is missing or empty.
---

# Skill: defining-constitution

## Overview
Guides the user to define the core project rules, architecture, and constraints.

## Checklist
1. Use the Read tool on `.specs/memory/constitution.md`. If it has content, exit and do nothing.
2. Ask the user about their project vision, tech stack, and core rules.
3. Once gathered, use the Write tool to save the definitions to `.specs/memory/constitution.md` following standard markdown formatting.
EOF
```

- [ ] **Step 3: Create defining-features skill**

```bash
mkdir -p skills/defining-features
```

- [ ] **Step 4: Write defining-features SKILL.md**

```bash
cat << 'EOF' > skills/defining-features/SKILL.md
---
name: defining-features
description: Use when starting a new project or when .specs/memory/features.md is missing or empty.
---

# Skill: defining-features

## Overview
Guides the user to define the list of features for the project.

## Checklist
1. Use the Read tool on `.specs/memory/features.md`. If it has content, exit and do nothing.
2. Ask the user to list the features they want to build (e.g., Auth, Database).
3. Use the Write tool to save the features to `.specs/memory/features.md` in a structured list format.
EOF
```

### Task 2: Update Startup Hook in CLAUDE.md

**Files:**
- Modify: `CLAUDE.md`

- [ ] **Step 1: Add initialization check to CLAUDE.md**

We need to add instructions for the agent to check the specs memory files upon initialization.

```bash
cat << 'EOF' >> CLAUDE.md

## Startup Instructions
When starting a conversation, you MUST check if `.specs/memory/constitution.md` and `.specs/memory/features.md` exist and are complete.
```

### Task 3: Enforce Context Loading in Planning Skills

**Files:**
- Modify: `skills/brainstorming/SKILL.md`
- Modify: `skills/writing-plans/SKILL.md`

- [ ] **Step 1: Update brainstorming SKILL.md**

We need to inject the Mandatory Context Gathering step. We will prepend it to the Checklist section.

```bash
sed -i '/## Checklist/a \
\n0. **Mandatory Context Gathering** — Use the Read tool on `.specs/memory/constitution.md` and `.specs/memory/features.md`. Do not proceed until you have read these files.\
' skills/brainstorming/SKILL.md
```

- [ ] **Step 2: Update brainstorming Output Paths**

We will change the output paths for specs generated by brainstorming.

```bash
sed -i 's|.specs/memory/docs/specs/YYYY-MM-DD-<topic>-design.md|.specs/memory/docs/specs/YYYY-MM-DD-<topic>-design.md|g' skills/brainstorming/SKILL.md
sed -i 's|Write design doc.*.specs/memory/docs/specs/|Write design doc to .specs/memory/docs/specs/|g' skills/brainstorming/SKILL.md
sed -i '/Write design doc.*docs\/superpowers\/specs\//a \
- MUST explicitly mention which feature(s) from `features.md` this spec refers to.' skills/brainstorming/SKILL.md
```

- [ ] **Step 3: Update writing-plans SKILL.md**

Inject Context Gathering step and update output paths.

```bash
sed -i '/## Scope Check/i \
## Mandatory Context Gathering\nBefore creating any plan, you MUST use the Read tool on `.specs/memory/constitution.md` and `.specs/memory/features.md`. Do not proceed until you have read these files.\n' skills/writing-plans/SKILL.md

sed -i 's|.specs/memory/docs/plans/YYYY-MM-DD-<feature-name>.md|.specs/memory/docs/plans/YYYY-MM-DD-<feature-name>.md|g' skills/writing-plans/SKILL.md

sed -i '/## Plan Document Header/a \
The plan MUST explicitly mention which feature(s) from `features.md` this plan implements.' skills/writing-plans/SKILL.md
```
